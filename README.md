# Noite Estrelada: Resgate Lunar

Jogo de shoot 'em up 2D onde **Miranda Margot**, a Guerreira das Estrelas, enfrenta as forças da
**Rainha da Escuridão** para resgatar a **Rainha da Lua** e devolver a luz ao universo.

## Documentação

- [Planejamento de Software (GDD)](docs/planejamento.md)

## Stack recomendada

- **Engine:** Godot Engine 4.3+ (GDScript)
- **Arte:** Pixel art 2D, resolução base 480x270 (escala inteira para 1920x1080)
- **Áudio:** OGG Vorbis (música) e WAV (SFX)
- **Distribuição:** itch.io / Steam (PC) e build WebGL

## Estrutura prevista

```
.
├── docs/            # Documentação e planejamento
```
